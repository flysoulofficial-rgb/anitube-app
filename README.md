# AniTube Android (WebView-обгортка)
Додаток відкриває https://anitube.in.ua — усе оновлюється разом із сайтом.
Збірка APK: GitHub → Actions → Build APK → Artifacts, або Android Studio → Build → Build APK.
User-Agent містить `AniTubeApp/1.0` — сайт може розпізнавати запити з додатку.
Колір бренду: res/values/colors.xml. Іконка: res/drawable/ic_launcher_fg.xml.
